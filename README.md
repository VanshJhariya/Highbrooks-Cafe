# The Highbrooks Cafe: website

Open `index.html` in a browser, or upload this whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel).

```
index.html            page structure and copy
css/styles.css        all styling and animation, split into numbered sections
js/main.js            order builder, live open/closed status, scroll motion
assets/images/
  gallery/            the 14 photos used in the gallery
  about/              photo beside the About section
  menu-photos/        original menu photos (source for the prices)
  unused/             extra photos, kept for later (the AI burger is marked)
assets/video/
  interior-tour.mp4   compressed loop used in the hero
  originals/          full-quality source videos
```

Edit prices in `js/main.js` (the `MENU` object). Edit hours in the `HOURS` array in the same file.
The phone number 09131100094 appears in `index.html`.
